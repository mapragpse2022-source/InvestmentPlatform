# 1. Purpose

This directory contains the foundational project documentation for the Digital Investment Platform.

The documents in this section define the project's purpose, vision, strategic goals and overall development roadmap.

Every contributor should review this section before working with any other project documentation.

The objectives of this documentation are:

- Establish a shared vision.
- Describe strategic goals.
- Provide the long-term development roadmap.
- Create a common understanding for all contributors.
