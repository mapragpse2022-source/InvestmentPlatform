# 1. Purpose

This directory defines the product itself.

It describes what will be built, who it is built for, which business problems it solves and how users interact with the platform.

Every implementation decision must align with the product documentation.

---

# 2. Objectives

The objectives of this documentation are:

- Define the product requirements.
- Identify target users.
- Describe user journeys.
- Define business rules.
- Establish product behaviour.
- Align engineering with business expectations.

---

# 3. Reading Order

The recommended reading order is:

2. PRD-002 User Personas
